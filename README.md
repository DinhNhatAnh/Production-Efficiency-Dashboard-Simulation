# Build-a-dashboard-and-create-a-dashboard-simulation

# 📌 Overview
This program helps leaders monitor and understand how effectively production is performing. Therefore, they can boost production and improve efficiency.

Additionally, there is a simulation sheet that allows leaders to see the efficiency for the following months when changes occur.

# 🛠️ Tools & Technologies
- Pivot Table
- Chart & Function
- Excel - VBA

# 📊 Dataset
Stimulated the data from 2022 to 2026

# 📈 Dashboard
- The efficiency by Month, Quarter, Year
- Top 10 Output Quantity by Model
