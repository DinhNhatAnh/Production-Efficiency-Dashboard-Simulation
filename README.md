# Production Efficiency Dashboard & Simulation

> An interactive Excel dashboard that helps production leaders monitor efficiency, plus a simulation sheet to see how efficiency changes when inputs change.

---

## 📌 Overview

This workbook helps leaders monitor and understand how effectively production is performing, so they can boost output and improve efficiency.

It also includes a **Simulation** sheet that lets leaders see the efficiency for the following months when changes occur.

---

## 🛠️ Tools & Technologies

| Tool | Purpose |
| --- | --- |
| **Pivot Table** | Summarize efficiency and output data |
| **Charts & Functions** | Visualize results and calculate efficiency |
| **Excel VBA** | Power the buttons, model selection and simulation |

## 🔮 Simulation Sheet

Use the controls below to test how changes affect efficiency.

| Control | What it does |
| --- | --- |
| **Dropdown list** | Choose a model name |
| **Take Model** | Shows all model names and style colors |
| **Calculate** | Calculates efficiency after the data is changed |
| **Clear All** | Resets the data |
| **Back** | Returns to the Dashboard sheet |

### How to use

1. Choose a model name from the dropdown list.
2. Click **Take Model** to load the model names and style colors.
3. Change the data you want to test.
4. Click **Calculate** to see the new efficiency.
5. Click **Clear All** to reset, or **Back** to return to the Dashboard.
